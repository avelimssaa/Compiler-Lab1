## Оптимизация IR.

![Оптимизация -O0](Optimize-IR.png)

Список оптимизаций:

1. sccp - свертка констант, вычисление выражений.
2. mem2reg - заменяет alloca/store/load на регистры
3. instcombine - упрощает арифметические выражения
4. dce - удаляет неиспользуемые инструкции

После применения оптимизаций исчезли операции с памятью в промежуточном представлении кода. В функции main мы сразу передаем в square константу 5 без операций выделения, заполнения и вызова памяти. В функции square мы выделяем память только для того, чтобы хранить значение умножения. В функции square исчезли операции с памятью для левого и правого бинарного оператора умножения, а сразу подставляются указатели на значение в аргументе функции.

## Вывод об оптимизации циклов в LLVM.

LLVM предоставляет мощные инструменты для проведения оптимизаций языка C. В рамках лабораторной работы была проведена оптимизация цикла for на языке C. Как можно увидеть из CFG неоптимизированного цикла for, в нем происходит очень много действий, занимающих память и прибавляющих программе время выполнения. Цикл for выполняет следующие действия: выделение памяти для чисел, обращение к ячейкам памяти, запись значений в ячейки памяти, проверка условий, переход к началу цикла. В данном случае, цикл проходит заранее известные этапы работы и заранее известное выполнение действий. Мы можем оптимизировать работу цикла, заранее просчитав значение, которое мы получаем после работы цикла. LLVM отлично справился с поставленной задачей оптимизации, и сократил выполнение программы до простого возврата константы, равноq 45, что видно из файла CFG, сгенерированного после оптимизации уровня -O2. Таким образом, LLVM предоставляет отличные возможности для оптимизации выполнения цикла for на языке C.
